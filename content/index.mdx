# DearOreUI

A LeviLamina client mod that loads OreUI and provides UI modification capabilities.

## Projects

- **[DearOreUI](https://github.com/DearOreUI/DearOreUI)** — LeviLamina client-side native mod, the core runtime.
- **[DearOreUI Designer](https://github.com/DearOreUI/Designer)** — Tauri-based visual designer for OreUI interfaces.
- **[DearOreUI Docs](https://github.com/DearOreUI/Docs)** — Development documentation source files.
