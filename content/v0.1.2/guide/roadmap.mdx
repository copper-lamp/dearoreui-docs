## 能力现状

- **真实显示链路**：只覆盖 OreUI 技术栈页面（如 `/play/all` 世界列表页）。
- **声明式 UI**：`registerOverlay` / `registerPanel` / `registerButton` / `registerPage` / `registerComponent` 已交付。
- **组件库**：37 种 `ComponentKind`（14 原子 + 23 组合），主题令牌对齐原版 `menus-theme` / `gameplay-theme`。
- **双向桥接**：C++→JS 已交付；JS→C++ 已验证一次 roundtrip，同页多次调用受限。
- **诊断**：`diagnostics.jsonl` 全事件流 + 21 项能力矩阵。
- **安全校验**：v0.1.2 起外部 `htmlBody` 注册即校验（fail-closed，S2）。

## 已知边界

| 边界 | 说明 |
| --- | --- |
| 页面范围 | 主菜单、世界内界面为 JsonUI 技术栈，不在当前覆盖范围 |
| JS→C++ 单发 | 每个 OreUI View 当前只有一次有效业务 dispatch，同页多次请求待攻坚 |
| 安全校验 | 含内联脚本 / 事件属性 / 外链 URL / `oreui://` 越界的旧资源会在 v0.1.2 注册失败，需改用页面脚本 |
| 组合组件交互 | 8.1.4 组合组件（dropdown 展开、modal 开关）仅渲染 + `state` 切换，点击事件 → C++ 分发在后续里程碑 |
| 离线预览 | M8.1.3 离线预览页仍是遗留 |
