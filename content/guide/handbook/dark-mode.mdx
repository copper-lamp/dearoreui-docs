# 深色主题

> OreUI 技术栈**原生就是深色**，不需要切换。DearOreUI 组件库直接复用原版深色设计变量，你的 UI 开箱即用就是深色风格。

## 为什么不需要切换

Minecraft 基岩版的 OreUI 页面（世界列表、设置、商城等）本身就是深色设计系统：

- 背景使用 `rgba(0,0,0,0.72)` 等深色面板色
- 文本使用白色（`#ffffff`）与弱化灰（`#b1b2b5`）
- 纹理使用原版 9-slice 深色材质

DearOreUI 组件直接消费这些原版变量，因此**自动继承深色观感**，无需任何额外配置。

## 对比

| 场景 | 表现 |
| --- | --- |
| 原版 OreUI 页面 | 深色 |
| DearOreUI 组件 | 深色（复用原版变量） |
| JsonUI 页面（主菜单 / 世界内） | 不支持（不在覆盖范围） |
