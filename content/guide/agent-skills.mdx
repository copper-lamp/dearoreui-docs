# Agent Skills

> DearOreUI 为 AI 辅助开发提供技能包（Agent Skills），让 AI 助手能按运行时契约生成正确的代码。这一页介绍可用的技能与使用方式。

## 什么是 Agent Skills

Agent Skills 是面向 AI 编码助手的**技能包**：把 DearOreUI 的 API 契约、组件库、能力矩阵打包成 AI 可直接消费的指令。AI 加载技能后，生成的代码与运行时能力严格对齐。

## 可用技能

| 技能 | 用途 |
| --- | --- |
| 组件库技能 | 生成 `ComponentSpec` 组件树代码（14 种组件） |
| API 契约技能 | 生成 `registerMod` / `registerOverlay` / `registerComponent` 等调用 |
| 能力查询技能 | 查询运行时能力矩阵，只生成可用的 API |

## 使用方式

在 AI 助手的提示中引用技能：

```text
使用 DearOreUI 组件库技能，生成一个包含标题和主按钮的面板。
```

AI 会按 `ComponentSpec` 契约生成：

```cpp
ComponentSpec panel;
panel.kind  = ComponentKind::Panel;
panel.label = "设置";

ComponentSpec button;
button.kind    = ComponentKind::Button;
button.variant = "primary";
button.label   = "确定";

panel.children.push_back(button);
```
