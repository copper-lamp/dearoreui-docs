## 示例 Mod（dearoreui-ExampleMod）

[dearoreui-ExampleMod](https://github.com/DearOreUI/dearoreui-ExampleMod) 是一个完整的外部 Mod 示例，演示：

- **桥接接入**：`DearOreUI_QueryApi` 获取 API 入口，带就绪重试（20 次轮询，10 秒窗口）。
- **状态中心**：`StateCenter` 注册 UI + 资源 + Host 方法 + 事件订阅。
- **全链路**：注册 → 显示 → JS 调用 C++ → 事件回传。

核心流程（`src/mod/MyMod.cpp`）：

```cpp
auto bridge = queryApi(1);                    // 探测 DearOreUI 桥
if (bridge.status != DearOreUIBridge_Ok) {
    // 未就绪：启动重试线程，就绪后交到客户端主线程
    return false;
}
mOreui = static_cast<dearoreui::api::IDearOreUIApi*>(bridge.api);
mModId = dearoreui::api::ModId{"example.state_center"};
mStateCenter = std::make_unique<StateCenter>(*mOreui, mModId, *this);
mStateCenter->registerAll();
```

## 在自己的 Mod 里复现

1. 按[安装与构建](./installation) 部署 DearOreUI。
2. 参考 [ExampleMod](https://github.com/DearOreUI/dearoreui-ExampleMod) 搭工程。
3. 按[快速开始](./getting-started) 注册第一个 Overlay。
4. 按[在你的模组中使用](./environment) 接入组件库与 Host 方法。
